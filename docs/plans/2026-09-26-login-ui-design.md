# 登录页 UI 优化设计

## 目标

在设置页内提供更接近桌面应用的登录体验，保留邮箱验证码、Apple 登录和轻语 API 授权三条现有认证路径，不增加品牌宣传区，也不改变认证接口。

## 设计决策

- 使用单栏、顶部对齐的表单，减少登录页在设置面板中的空白跳跃。
- 邮箱验证码是主路径，使用唯一的蓝色主按钮。
- Apple 和轻语 API 授权降为纵向次级按钮，并标明系统授权或浏览器授权方式。
- 移除重复的“账户访问 / 欢迎回来”标题层级，保留简洁的“登录 AiOffice”标题。
- 保留显式标签、键盘焦点环、错误提示和加载状态，兼容浅色与深色主题。

## 验证

- 运行 Shell TypeScript 类型检查和构建。
- 检查登录表单的邮箱、验证码、发送冷却、登录中、错误和第三方授权状态。
